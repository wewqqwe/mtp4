# Лабораторная работа №4

Осетрова Алина Романовна, группа 221141, вариант 3, лабораторная №4

Тема: сумма через reduce; генератор Фибоначчи; генератор случайных чисел в диапазоне; карринг; бесконечный генератор случайных данных

## Постановка

Функциональные задачи варианта 3: свёртка суммы, бесконечный ряд Фибоначчи, включительный случайный диапазон, каррирование сложения и неисчерпаемый поток записей. Шаги вынесены во вспомогательные модули.

## Соглашения варианта

- Простые числа: все простые от 2 до 100 включительно; само число 100 простым не является.
- Список Фибоначчи и генератор начинаются с 0, 1.
- Границы диапазона случайных чисел включительные.
- Слова выделяются выражением `[0-9A-Za-zА-Яа-яЁё]+` и приводятся к нижнему регистру.
- Карринг: f(a)(b) == f(a, b).

## Состав

- `reduce_sum.py` — сумма через `functools.reduce`.
- `fib_gen.py` — генератор Фибоначчи.
- `randspan.py` — генератор случайных чисел в диапазоне.
- `curry.py` — карринг сложения.
- `endless.py` — бесконечный генератор случайных данных.
- `folding`, `progression`, `sampling`, `calls` — вспомогательные модули.

## Запуск

```bash
python main.py
python -m pytest
```

Зависимость для проверок указана в `requirements-dev.txt`. Код лабораторной использует только стандартную библиотеку.
